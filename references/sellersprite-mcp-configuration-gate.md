# 卖家精灵 MCP 配置与能力核验门槛

此门槛属于阶段零，发生在输入预检和四阶段 Listing 流程之前。目标是确认当前运行环境已实际配置并暴露可用的卖家精灵 MCP；不是从固定文件路径、历史会话或工具名称猜测配置状态。

## 通过条件

按以下顺序检查当前会话：

1. 列举当前可用的 MCP 连接/服务和工具目录；确认一个工具组可由连接元数据、服务说明或工具说明唯一证明为卖家精灵/SellerSprite。
2. 在同一已确认工具组中，唯一映射以下业务能力，并核对其用途、必要输入与核心输出语义：

   | 必需能力 | 最低可确认语义 |
   | --- | --- |
   | `asin_detail` | 以 ASIN 和站点获取商品详情；可返回 ASIN、标题或其他基础商品识别字段 |
   | `review` | 以 ASIN 和站点取得评论记录列表或明确的空列表 |
   | `traffic_keyword` | 以 ASIN 和站点取得流量关键词记录列表或明确的空列表 |

3. 若连接提供安全的初始化/健康检查，执行它以确认连接可用；没有此能力时，不伪造 ASIN 请求。后续阶段一的首次真实调用才是数据权限的进一步验证。
4. 记录“阶段零通过”、连接/工具组的当前可见标识和三项能力映射。该记录只写工具能力和状态，不写 URL、令牌、密钥、Cookie 或本机配置路径。

只有上述四项均成立才可输出阶段一的固定提示。

## 未通过时的唯一处理

下列任一情况均为未配置或未就绪：没有卖家精灵连接；连接未启用；工具未在当前会话暴露；候选服务不唯一；三项必需能力任一缺失或无法确认；初始化、鉴权或连接失败。

第一句先写明具体暂停原因，再给出处理方式并停止：

```text
跨境吴老师当前暂停 Amazon 新品 Listing 文案：<卖家精灵 MCP 未配置、未启用、未授权、能力缺失、绑定歧义或调用失败的具体原因>。请在当前 Agent 环境完成卖家精灵 MCP 的添加、启用或授权，并重新加载工具；完成后告知我“已配置”，我会从阶段零重新核验。
```

不要使用相近工具、其他数据源、缓存响应或虚构竞品数据继续。不要假定 MCP 服务名、命名空间、配置文件位置、URL、端口、认证方式或密钥字段；不要要求用户在聊天中提交秘密信息，也不要自动改写用户的持久化配置。

## 用户完成配置后的重试

收到“已配置”或等义确认后：

1. 重新列举当前会话 MCP 目录；如桌面应用要求刷新或重启，等待工具目录实际出现后再检查。
2. 重新执行本门槛的三项能力映射；上一次失败的工具清单不可复用。
3. 仍未通过时，重复报告当前缺口；通过后才进入输入预检和阶段一。
